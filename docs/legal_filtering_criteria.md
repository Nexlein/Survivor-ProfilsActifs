# Critères de Filtrage (Recruteurs)

1. **Secteur Cible (`targetSector`)** : Justification : Permet au recruteur de cibler les candidats recherchant activement dans son domaine d'activité.
2. **Compétences (`skills`)** : Justification : Permet d'identifier les candidats possédant le savoir-faire technique ou fonctionnel requis pour le poste.
3. **Permis JEB (`hasWorkPermit`)** : Justification : Garantit un niveau d'aptitude professionnelle validé par l'État.

*Aucun critère fondé sur l'apparence physique, l'âge, l'origine ou le sexe n'est exposé, conformément à l'article L1132-1 du code du travail.*
